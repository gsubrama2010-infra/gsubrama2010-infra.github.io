AI components

  • Anthropic Claude API behind five features: a streaming assistant, vision and PDF extraction into strict JSON schemas, data-driven recommendations and multilingual content generation.
  • Adaptive thinking, effort control and structured outputs, grounded in live, row-level-secured database context instead of a vector store.
  • Real-time conversational video avatar (Runway) with a daily spend budget and race-safe credit reservation.
  • Prompt-injection hygiene: user content is treated as data, and model output is validated and sanitized before use.

MCP server

  • TypeScript MCP SDK over stateless Streamable HTTP, deployed as serverless functions.
  • 11 read-only tools split across a public endpoint and an authenticated account endpoint.
  • OAuth 2.1 with RFC 9728 protected-resource metadata, JWT verification and a consent screen with MFA step-up.
  • Defense in depth: a database-level guard rejects any write made with an assistant-issued token, plus per-user and per-IP rate limits.

Integrations

  • Stripe: saved cards, off-session charges, Connect payouts, signed webhooks and idempotency keys.
  • A second, regional payment gateway, routed per market through a static-IP egress proxy.
  • Resend email, Twilio SMS and Expo push notifications (FCM), with per-user preferences.
  • Google Places, OpenStreetMap and headless Chromium rendering behind SSRF protection; Sentry and Vercel Analytics for observability.

Data & backend

  • Supabase Postgres, Auth, Storage and Realtime: about 45 tables and 76 row-level security policies, with no ORM.
  • Event pipeline on pg_cron, pg_net and pgmq with retries, exactly-once claim keys and archived failures.
  • Sign-in by magic link, password, Google OAuth, SMS one-time code and authenticator-app two-factor.
  • Multi-market design: several currencies, time zones and three interface languages.

Apps & delivery

  • Next.js 16 (App Router, server actions) on React 19 and TypeScript: about 25,000 lines.
  • Android app on Expo SDK 54 and React Native: about 7,000 lines.
  • Vercel deploys on every push to main; GitHub Actions builds the signed Android release.

Operations & security

  • Automated full backups checked against a row-count manifest, with restore runbooks for data loss and full-project loss.
  • Incident and rollback runbook.
  • Security headers (CSP, nosniff, Referrer and Permissions policies); visitor IPs stored only as hashes.
  • Cost controls on public AI endpoints: per-IP limits and daily circuit breakers.
