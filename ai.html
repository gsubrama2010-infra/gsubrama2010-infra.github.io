$ cat CONTRIBUTING.md

AI speed. Human-approved change.

AI makes me faster, but it never gets to skip review. Every infrastructure change takes the same path from idea to production.

  1. 01 Draft with AI

    Claude in VS Code speeds up code generation, automation and troubleshooting.

  2. 02 Plan

    Terraform saves an explicit plan, so the change is visible before anything runs.

  3. 03 Review

    A person reviews and approves that exact plan. Nothing unreviewed reaches production.

  4. 04 Apply

    GitHub Actions applies only the reviewed plan, per environment, with a full audit trail.

  5. 05 Verify

    Drift detection across DEV, QA and PROD, with rollback runbooks ready.
